URL: http://{{ h }}:{{ mcp.port }}{{ mcp.path }} · Token: {{ mcp.token }}

Löst der Hostname auf deinem Rechner zuerst per IPv6 auf, ist der Port nicht erreichbar (Docker-Portfreigaben gelten unter Home Assistant OS nur für IPv4). Dann die IPv4-Adresse des Pi einsetzen und sie im Router fest vergeben.

Claude Code:

claude mcp add --transport http bulltraining http://{{ h }}:{{ mcp.port }}{{ mcp.path }} --header "Authorization: Bearer {{ mcp.token }}"

Claude Desktop (claude_desktop_config.json, benötigt Node.js):

"bulltraining": {"command": "npx", "args": ["-y", "mcp-remote", "http://{{ h }}:{{ mcp.port }}{{ mcp.path }}", "--allow-http", "--header", "Authorization: Bearer {{ mcp.token }}"]}
