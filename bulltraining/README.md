# bulltraining

Endurance training planning with intervals.icu, performance tests and an MCP server for Claude.

- Plans built from your performance tests (FTP, threshold pace, CSS) and your current training volume
- Load corridor: no sudden jumps, no silent underload; recovery weeks and taper
- Claude proposes changes via MCP, you confirm them – with reason, diff and undo
- Workouts published to intervals.icu (and from there to Garmin)

User interface in German. See the **Documentation** tab for setup.
